## 可做性判断的边界

路径：市场来源商品 → 新建单规格候选 → 明确同规格竞品 → 选择 1688 商品及其真实 SKU → 可下单凭证 → 包装与物流/合规核实 → 完全成本与资金 → 人工试验审核。

判断有四种结果：

- 资料不足：关键证据缺失或过期，不给完整利润达标结论。
- 当前方案不通过：已有证据表明超价、利润不足、库存/MOQ/交运期限/资金/禁做品类不符；仍列出其余缺口。
- 人工暂缓：保留资料和处置原因。
- 可进入人工试验审核：通过当前已填资料与数值门槛，但不保证销量、净利或履约。始终 `canPublish=false`、`canPurchase=false`。

完整财务输出要求：实际 SKU 映射、报价确认及有效期、销售单元数量、MOQ/库存、每项费用金额与依据、适用且核实的规则版本、计划成交价和买家运费。0 必须是有凭据的零，不是默认缺省。

平台佣金/物流费用/普通交易费或分期费/增长费/推广准备/收款费/订单固定费沿用原型公式，仅在操作者确认本店适用基数后用于核算。税费、售后准备和固定费分摊仍为可追溯的规划输入，不是已实现净利润。不同实际收费基数或税制若无法表达，必须改模型后再判定，不能强塞进演示公式。

单件利润 = 商品成交收入 CNY − 全部适用成本；两个利润门槛同时满足，最低价仍须低于店主经营上限和经证据确认的市场上限。六种压力幅度来自原开发验收场景，不是对未来价格的预测。资金按采购批量先垫付、其他成本全额保守预留，不代表真实回款时间表。

## 连接与安全

连接地址依据 [Sorftime 官方 MCP 页面](https://www.sorftime.com/en-US/mcp)，使用官方 `mcp.sorftime.com` HTTPS 服务，密钥不落业务数据库或日志。协议按 [MCP Streamable HTTP 规范](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports) 支持握手、工具目录、JSON/SSE 与会话标识；工具运行时仍检查实际参数契约。

- 只有 9 个已适配的只读调研工具；Shopee 限 PH；页码 1–5；趋势需明确起止日期且最多 365 天。
- 不允许自定义转发地址；遇重定向停止，不转发凭证。
- 一次采集任务执行一项查询；货源详情与 SKU 按两项查询处理。不自动重试、购买或充值。
- 单次外部响应最大 12 MB，手动上传 JSON 最大 7 MB；只读导入需 `events` 数组，最多 50 次采集记录。
- 原始数据错误或字段契约变化先隔离。类别/趋势的未知结构先存快照，不强行解释。
- 请求参数、工具、时间与结果状态留存；密钥不包含在页面状态、快照索引或完整备份中。
- 仅监听本机 `127.0.0.1`，检查 Host、来源和会话令牌。无多用户账户系统，不可直接改成公网服务。
- 本地数据库不是不可篡改账本；手动凭证输入不代表已验真。请保管供应商报价和备份，不提交公开仓库。

```json
  "schemaVersion": 1,
  "label": "自定义批次说明",
  "events": [
    {
      "tool": "shopee_product_search_from_name",
      "args": {"site": "PH", "name": "你的搜索词", "page": 1},
      "fetchedAt": "实际采集时间，ISO 格式且包含时区",
      "response": {"content": [{"type": "text", "text": "完整原始 MCP JSON 文本"}]}

  ]

```

上面仅为格式示意，不是有效市场证据。页面导入始终记录为“人工导入”，不会接受文件自称“后台实时采集”。命令行导入工具会先生成 SQLite 备份，重复相同导入不会重复造商品。
