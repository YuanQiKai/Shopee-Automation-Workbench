# Sorftime字段契约与本地审核

## 工具与证据

调用前读取当前MCP工具说明/运行时schema。允许Shopee PH与1688只读检索；关键词收藏修改、采购、聊天、充值、广告或上架不是选品读权限。每响应留：工具、参数、返回原文、实际采集时间（UTC+本地时区）、数据服务来源、哈希和接口文档版本。不同返回分别记录时间；不能让新SKU响应刷新旧商品详情/MOQ的时间。

顺序：PH查询找同规格市场 → 1688中文/图片检索候选 → `ali1688_product_request(product_id)` → `ali1688_product_variations(product_id)` → 比较主备 → 准确SKU数量阶梯/税票/库存/包装/时效复核 → 完整成本。两个工具分别对主供和备供调用；商品详情的起价、总库存和SKU记录不能互相代替。

|原字段|保留/归一化|决策要求|
|---|---|---|
|product_id / offer ID|字符串；可追查真实1688链接|不可杜撰ID|
|sku_id / sku_name|逐SKU字符串及完整属性|材质/尺寸/件数/配件/包装逐一匹配销售规格|
|price / offer_price|两列CNY原值都保留|不相等标冲突；未确认不能任选较低。保守上界可演算，但标假设|
|wholesale_price_range / min_order_quantity|商品级阶梯与MOQ|需确认当前SKU、采购数量及代发场景，不能擅升为SKU级事实|
|stock / stock_count|SKU库存/商品总库存分开|零库存不是缺值；报价库存24h内刷新；销售单元套装数量要换算|
|length/width/height|cm；0代表未填写，归一化null并保留原0|不能当零体积包裹|
|weight|kg；乘1000转g时使用Decimal|商家自填保留标签；不能等于云仓完整包装实测|
|pkg_size_source|原文|商家自填≠第三方实测|
|shipping_time|必须解析成带单位的时长|城市名或模糊字段标无效；不按工具示例编造24h|
|is_drop_shipping|布尔原文|商品级声明；最终SKU是否可一件代发仍确认|

实测异常（2026-09-15）：625255182969共32SKU，包装尺寸0、时效返回义乌市；705110577312共6SKU，包装商家自填、时效也是义乌市。存在展示价与offer_price四舍五入般差异，不能武断纠正服务商数据。两家不同商家仅代表有备用线索，不代表同规格通过。

主候选洗衣网袋细网大中小3件套SKU4437596177689，展示4.9、报价字段5元；备用商家只返回单袋SKU。必须匹配30×40、40×50、50×60三件组合并核实数量、采购价、仓库SKU种数及整包重量；不能直接拿一个单袋替代套装。无可比较的成套备供时保留备用商家但备供SKU待补。

## 网页工作台

本机文件：`C:/Users/admin/Documents/ChatGPT/自动选品上架/workbench`。启动后 `http://127.0.0.1:3010`。Next.js+Tailwind+shadcn/ui / FastAPI / PostgreSQL / Temporal。原mvp保留。

- 审核总览/清单：事实、推断、建议、定量市场检查、缺口和版本。
- 货源库：主商家/备商家准确SKU和冲突；绑定不自动放行。
- 成本：店铺公共配置+单品成本金额、渠道、准确销售单元；保存才重算。
- 经营资金：现金/承诺/损失均用今天数据；历史启动预算不可替代。
- 证据：原始MCP快照和官方资料定位，用户补充观测JSON及门槛凭证。
- 人工审核：只有硬门槛、主备、资金均通过才可批准；并发保存/审核有版本检查和数据库锁。改变输入使批准失效，但占资不自动消失；人工退回/否决后才释放本地测试预留。不取消真实外部订单。
- API：在本机加密保存密钥；对话MCP凭证不自动共享本地后端，不私自复制私密配置。OpenAI兼容/Anthropic/Gemini可以手工选择协议与自定义根地址/模型；第三方名称不是已兼容证明。调用AI前由用户在网页确认外发证据和可能费用，AI不能修改判定。
- 调研任务：真实Temporal队列；错误/额度不足不自动无限重试；已取得原始结果仍可能字段不足。未来SP-API、Ads、ERP、汇率连接明确标规划，不能虚称接通。

本地模式仅监听127.0.0.1；PostgreSQL为业务数据库。Temporal本地开发服务将自身任务历史持久到本地文件，不是生产集群。未建立多用户登录、云端网络暴露或生产部署；不要直接发布到公网。

## 程序使用

`python scripts/workbench_client.py --action export --output /path/审核.xlsx` 导出当前库。`--action status` 读取本地数量与缺口。网页中的“重算全部”检查现有数据，不等于新增市场抓取。

完整自动采集还取决于本地Sorftime密钥、可用配额、可靠PH/PHP窗口数据与供应商补证。首次导入22条历史候选和38SKU，符合测品条件仍可能为0。不可为了每日10–20目标捏造证据/价格，不能把同款尺寸变体当新增SPU。
